Printers

Leave Name empty to use the name set in the printer's Mainsail. Host is the printer's address. Camera and Screen list the cameras and screen pages set up in the printer's Mainsail (its Moonraker webcam list); pick Custom… to type a path on that host or a full URL instead. The camera picked here is also the one the server checks for failures. Changes are saved in this browser.

Detection, alerts and timelapses

Each printer's row above has its server settings under it: tick Watch to have the PrintWarden server handle it. Timelapse: Render frames renders moonraker-timelapse frames on the server; Copy videos copies finished videos from printers that render on-device (Snapmaker U1). Spaghetti (Obico's model) and Moved parts each have their own setting: Alert notifies; Alert + pause also pauses the print. These live on the server, so they apply to everyone, and Save applies them at once.

Alerts and checks (all printers)

The webhook URL is never shown again once saved, here or anywhere else; paste a new one to replace it. Scoring follows Obico's failure detection: the first 30 checks of a print (5 min at 10 s) only learn what the print normally looks like; its thresholds are tuned for 10 s. Moved parts compares the last 2 minutes of snapshots with the 2 minutes before.
